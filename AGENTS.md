# Repository guidance

## Before changing code

Read [preference.md](preference.md) and follow its instructions before changing any code.

Do not change [preference.md](preference.md) or [docs/memory-evaluation-steps.md](docs/memory-evaluation-steps.md) unless Sneha explicitly asks for and approves the change.

## Project purpose

This project is building a longitudinal memory evaluation benchmark for an AI note-taking product. The product listens to a user's conversations 24/7 through on-device iPhone audio and can access the user's email and calendar.

Read [docs/memory-evaluation-steps.md](docs/memory-evaluation-steps.md) to understand how the project and repository are being built from scratch.

## Reference material

The project draws conceptual inspiration from the paper [ES-MemEval: Benchmarking Conversational Agents on Personalized Long-Term Emotional Support](https://arxiv.org/html/2602.01885v1) and its corresponding [GitHub repository](https://github.com/slptongji/ES-MemEval).

Use the paper for conceptual guidance and the GitHub repository as an implementation reference. Build a custom solution grounded in this project's requirements. Do not copy the reference project's code or solutions as-is.
